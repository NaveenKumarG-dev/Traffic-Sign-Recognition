# GTSRB Dataset

This directory is used for any local dataset storage.

The GTSRB dataset is downloaded via KaggleHub and cached in the Kaggle cache directory.
The download path is discovered dynamically - no hardcoded paths are used.

## Dataset Info

- **Name**: German Traffic Sign Recognition Benchmark (GTSRB)
- **Classes**: 43 traffic sign categories
- **Source**: [Kaggle - GTSRB](https://www.kaggle.com/datasets/meowmeowmeowmeowmeow/gtsrb-german-traffic-sign)
